6502-KIM

A.C. Wright 6502
Keypad Input Monitor
Overview
The 6502-KIM (Keypad Input Monitor) is A.C. Wright's tribute to the legendary KIM-1 single-board computer. There is no full keyboard and no monitor screen — just a hex keypad and a small 16×2 character LCD. You talk to the machine the old-fashioned way: by keying in hexadecimal addresses and data, byte by byte, exactly as hobbyists did in 1976.
History
The original KIM-1 (Keyboard Input Monitor) was released by MOS Technology in 1976 for about $245 to show off their brand-new 6502 chip. With a hex keypad, a six-digit LED display, and a 1 KB monitor ROM, it became many people's first computer and launched a generation of 6502 hobbyists. This homebrew KIM rebuilds that experience from AC6502 parts — a Main Board, Serial Card, and a custom Keypad Card — running the KC Monitor cartridge.

At This Party
This KIM has a small white reset button on the Main Board near the front. Press it to restart the KC Monitor. Wired to the breadboard are 8 LEDs — key in one of the two demo programs printed on the cards beside it, press run, and watch them dance.
Don't expect a desktop — this machine is all about poking values straight into memory with the keypad and reading them back on the little LCD, exactly like 1976.

Did You Know?
The original KIM-1 sold for about $245 in 1976 and was many hobbyists' very first computer.
The KC Monitor runs a second monitor over serial at the same time — it speaks the same language as the Apple I's “Wozmon.”

The Keypad Card
The custom Keypad Card reads the 24-key pad through a 74C922 encoder into a 65C21 PIA, firing an interrupt on every press — so the monitor never misses a key.

Getting Started
Power on (or press Reset) and the KC Monitor takes over, showing the current address and the byte stored there on the 16×2 LCD. The monitor has two modes: navigation (move around memory) and data-edit (change bytes). Press INS to toggle between them.

The Breadboard LEDs
The breadboard adds 8 LEDs behind a 74HC373 latch. Writing a byte to address $9400 lights the LEDs to match that byte's bits — store $FF and all eight glow.
Two ready-to-key-in programs are printed on separate sheets: a KITT scanner (a lit LED bouncing back and forth) and an 8-bit binary counter.
To run one: press INS to enter edit mode, key the bytes into RAM (the LCD shows each address and value), then press ▲ at the start address. Watch the LEDs — press ESC to stop.
Serial Monitor (Optional)
Attach a terminal to the Serial Card at 19200 baud, 8-N-1 for a roomier view. At the > prompt:
TypeAction
XXXXExamine the byte at address XXXX
XXXX.YYYYExamine a range of memory

The serial and keypad monitors share the same memory, so you can key in bytes by hand and then examine them over serial — or the reverse.
Tips
With only two lines of LCD, work one address at a time: read a byte, change it, step forward with ►, and watch the value update.
Programs run as subroutines — always end yours with an RTS so control returns cleanly to the monitor.
More To Try
Light a pattern — in edit mode, store different bytes to $9400 and watch which of the 8 LEDs turn on. $AA lights every other one.
Explore the ROM — point the address at the monitor ROM and step through it byte by byte to see the code that makes the KIM tick.
Leave a message — write a short sequence of bytes into RAM, then come back later (without resetting) and read them back to prove the memory remembered.
