6502-ACE

A.C. Wright 6502
All-in-One Computer Experience
Overview
The 6502-ACE (All-in-one Computer Experience) is a complete, self-contained 65C02 computer on a single PCB — designed and built by A.C. Wright. It folds everything found across the modular COB's expansion cards — CPU, memory, video, audio, storage, serial, GPIO, real-time clock, and keyboard controller — onto one board with an integrated Cherry MX mechanical keyboard, delivering the full AC6502 experience with no backplane required.
History & Design
The ACE is part of the AC6502 family — a set of open-source homebrew computers that all share one architecture, one memory map, and one common BIOS (kernel + machine-code monitor + BASIC). Where the original 6502-COB spreads its functions across plug-in cards on a backplane, the ACE integrates them into a tidy all-in-one machine in the spirit of the classic 8-bit home computers of the late 1970s and early 1980s. Built around the Western Design Center W65C02S — the modern, fully-static CMOS descendant of the 1975 MOS 6502 — it bridges vintage design with present-day parts.

At This Party
This ACE has a small white reset button just above the ESC key. Tap it any time to restart the machine back to the BASIC prompt — perfect if a program runs away or the screen looks stuck. The keyboard is built right in, so just start typing!

Did You Know?
The entire operating system — kernel, machine-code Monitor, and a full BASIC interpreter — fits in a single 32 KB EEPROM.
The Pico9918 video card is a Raspberry Pi Pico pretending to be the 1979 TMS9918A graphics chip found in the ColecoVision and MSX.
The ARMSID reproduces the legendary Commodore 64 “SID” sound chip using a modern ARM microcontroller.

Getting Started
Flip the power switch and the ACE boots straight into BASIC, showing a banner and the READY. prompt. Everything is typed at this prompt. Press ESC at boot (or type BRK handlers) to drop into the machine-code Monitor instead; type X in the monitor to return to BASIC.

Fun To Try (No Disk Needed)
Endless name scroll — type:
10 PRINT "ACE ";
20 GOTO 10
then RUN. Press Ctrl+C to stop.
Make some noise — SOUND 0,440,50 plays a 440 Hz tone. Try different frequencies. Set volume with VOL 15.
Random art —
10 PRINT CHR$(INT(RND(1)*2)+177);
20 GOTO 10  — fills the screen with a maze pattern.
Wozmon easter egg — from BASIC type SYS $FF00 to jump into a built-in copy of the original Apple I monitor.
Wiggle the joystick — PRINT JOY(1) shows a live number that changes as you move a plugged-in Atari joystick.
