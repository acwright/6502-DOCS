Monitor Reference

A.C. Wright 6502 BIOS
Machine-Code Monitor
Entering & Exiting the Monitor
Enter via ESC at boot — cold entry; prints MONITOR banner. Prompt is .
Enter via BRK from BASIC — prints BRK AT $xxxx and current register state.
Enter via hardware BRK — any BRK opcode in user code enters monitor with full register display.
Exit to BASIC — type X.  Wozmon easter egg: type G FF00 or SYS $FF00 from BASIC to enter the original Apple I Wozmon at $FF00.
Register Display Format
PC=XXXX A=XX X=XX Y=XX SP=XX NV-BDIZC
Saved CPU state is shown on BRK entry and after J. Edit with ; command. Flags: N=Negative V=oVerflow — B=Break D=Decimal I=Interrupt Z=Zero C=Carry.
Memory Inspection
CmdSyntaxDescription
M M [addr] [addr] Hex + ASCII memory dump, 8 bytes/line. Bare M continues from last address
D D [addr] [addr] Disassemble 65C02 instructions (20 lines default). Full WDC 65C02 + Rockwell instruction set
R R Display saved CPU registers: PC, A, X, Y, SP, and flag bits
Memory Manipulation
CmdSyntaxDescription
> > addr byte [byte…] Deposit (write) one or more bytes starting at address
F F addr addr byte Fill memory range with a constant byte value
T T addr addr dest Transfer (copy) a memory block to dest. Handles overlapping regions correctly
H H addr addr byte [byte…] Hunt (search) for a byte pattern in the specified range. Prints each matching address
C C addr addr addr Compare two memory regions of equal length. Prints addresses where bytes differ
Execution Control
CmdSyntaxDescription
G G [addr] Go — JMP to address (or saved PC). Restores all registers via RTI
J J [addr] JSR — call subroutine at addr; RTS returns to monitor with register display
; ; PC xxxx A xx X xx … Modify saved registers. Specify any subset in any order. Changes take effect on next G
File I/O & Utilities
CmdSyntaxDescription
L L "file" [addr] Load from CompactFlash (with filename) or XModem (no filename) to addr (default $0800). Loading at the default address lets X hand the program to BASIC ready to RUN
S S "file" addr addr Save range to CompactFlash (with filename) or XModem (no filename)
@ @ List current disk's directory; prints DISK n header (same as BASIC's DIR)
# # NN Select CF disk bank NN (hex 00–FF); bare # reports current disk. L, S, and @ all operate on the selected disk automatically
N N value Number base conversion. Input: $xx=hex, +ddd=decimal, %bbbb=binary. Shows all three bases
X X Exit monitor and return to BASIC
Graceful Degradation
Hardware AbsentMonitor Behavior
CompactFlashL, S, @ print I/O ERROR; StWaitReady times out instead of hanging
SerialXModem L/S (no filename) return error
Address Input Format
All addresses and byte values are entered as hexadecimal without a prefix (e.g. 0800, FF). Ranges are two space-separated addresses: 0800 09FF. The N command accepts $, +, or % prefixes for base conversion input only.
